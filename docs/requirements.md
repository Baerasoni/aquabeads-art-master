# アクアビーズアートマスター 要件定義書

写真をアクアビーズ（エポック社）の図案に変換する Web アプリ。

作成日: 2026-08-12

## 1. 背景と目的

アクアビーズで写真やイラストを再現しようとすると、「どのマスにどの色を置くか」を手作業で考える必要がある。
本アプリは写真をアップロードするだけで、実際のビーズトレイに合わせた図案・必要ビーズ数・印刷用原寸シートを自動生成する。

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| 形態 | Web アプリ（React + TypeScript + Vite） |
| 公開 | GitHub Pages |
| 出力物 | ①図案表示 ②色ごとの必要ビーズ数リスト ③印刷用原寸シート |
| 色パレット | 公式全色をプリセット化し、手持ちの色だけチェックして使用 |
| UI 言語 | 日本語 |
| デザイン | Apple 風の洗練されたミニマルデザイン |

## 3. 機能要件

### 3.1 画像入力
- ドラッグ&ドロップ / ファイル選択（JPEG / PNG）
- 画像はサーバーに送信せず、すべてブラウザ内で処理する（プライバシー保護）

### 3.2 グリッド設定
- **六角（オフセット）グリッド**。行ごとに半ピッチ（2.5mm）ずれる
- プリセット: 標準ビーズトレイ（偶数行22個 / 奇数行21個 × 26行 = 559マス）
- 行数・基準列数は自由入力も可能（大きい作品はトレイ複数枚で分割制作）

### 3.3 画像調整
- 明るさ / コントラスト / 彩度スライダー（減色前の前処理）

### 3.4 減色（量子化）
- 六角配置の各セル中心で画像をサンプリングし、選択中パレットの知覚的最近傍色（CIELAB ΔE）にマッピング
- ディザリング ON/OFF 切替（v1 は OFF デフォルト。六角格子用に誤差拡散の隣接セルを調整）

### 3.5 図案表示
- 六角配置の円でビーズ色を表示
- 各セルに色記号を併記（白黒印刷・色覚多様性でも判別可能に）
- 行番号ルーラー付き

### 3.6 必要ビーズ数リスト
- 「あか×34、みずいろ×12…」形式の色別必要個数と合計
- 集計合計はグリッド総マス数と一致すること（検証条件）

### 3.7 印刷用原寸シート
- 公式イラストシートと同方式（印刷してトレイの下に敷く）
- 横ピッチ 5.0mm・行間 4.33mm の原寸を mm 単位 CSS + `@media print` で再現

### 3.8 手持ち色設定
- 公式全色プリセットからチェックボックスで選択
- `localStorage` に永続化

## 4. 非機能要件

- 完全クライアントサイド（外部送信なし）
- スマホブラウザでも操作可能なレスポンシブ UI
- GitHub Pages（静的ホスティング）で動作

## 5. 公式仕様（aquabeadsart.com 調査済み・2026-08）

公式「オリジナル用ビーズトレイシート」PDF（`/ja-jp/sites/default/files/2023-01/501.pdf`）の描画データ解析により確定。

### 5.1 グリッド仕様
| 項目 | 値 |
|---|---|
| 並び方 | 六角（オフセット）配置。正方格子ではない |
| 横ピッチ | 5.0mm |
| 行間隔 | 約 4.33mm（= 5 × √3/2） |
| 標準トレイ | 偶数行22個 / 奇数行21個 × 26行 = 559マス |
| ビーズ直径 | 約 5mm（シート上の位置マーカー円は直径 4mm） |
| 公式シートのページサイズ | 560×746pt（197.5×263.1mm）、トレイ枠は約 109×113mm |

### 5.2 色ラインナップ（公式ビーズ対応表）
- まるビーズ 48色（基本16色 + パステル系4色 + メタル系9色 + ゴールド/シルバー/ブロンズ + マーブル7色 + ネオン7色 + とうめい 等）
- キラキラビーズ 8色 / ポリゴンビーズ 41色 / スタービーズ（別形状）
- RGB 値は公式色見本 PNG（`/ja-jp/asset/img/about/beadslist/img_m_01.png` 〜）をピクセルサンプリングして生成する
- 注意: 公式サイトは通常の HTTP 取得を 403 でブロックするため、取得はブラウザセッション経由で行う
- 公式注記「ビーズの色味は生産ロットにより多少異なる」→ パレットはデータとして外出しし、後から調整可能にする

## 6. アーキテクチャ

```
src/
  App.tsx                 — レイアウトと状態の親（useState/useReducer、状態ライブラリ不使用）
  components/
    ImageDropzone.tsx     — 画像入力
    GridSettings.tsx      — グリッド設定・画像調整スライダー
    PaletteSelector.tsx   — 手持ち色チェック（localStorage 永続化）
    PatternGrid.tsx       — 図案表示（Canvas 描画）
    BeadCountList.tsx     — 必要ビーズ数リスト
    PrintSheet.tsx        — 印刷用原寸ビュー
  lib/                    — UI 非依存の純関数ロジック（Vitest 対象）
    palette.ts            — アクアビーズ色定義（名前・記号・RGB）
    grid.ts               — 六角グリッド定義（行ごとの列数・セル中心座標・mm 座標）
    colorspace.ts         — sRGB→CIELAB 変換・ΔE 色距離
    quantize.ts           — 六角セル中心サンプリング・最近傍マッピング・ディザリング
    pattern.ts            — Pattern 型（行ごとに長さの異なる配列の配列）・色別集計
```

処理パイプライン（すべてブラウザ内）:

```
File → createImageBitmap → canvas 描画 → ImageData
     → 六角セル中心ごとに周辺画素を集約（grid.ts）
     → パレット最近傍マッピング（quantize.ts）
     → Pattern → 図案表示 / 集計 / 印刷
```

六角配置のため「canvas を縮小して 1 セル = 1 画素」方式は使えない。
セル中心座標（奇数行 +2.5mm オフセット）ごとに半径内の画素を集約する。

## 7. 検証方法

- `npm test`（Vitest）: lib の純関数テスト。標準トレイのセル総数 = 559 など
- `npm run dev` + ブラウザ: サンプル写真で図案・ビーズ数・印刷プレビューを目視確認
- ビーズ数リストの合計 = グリッド総マス数
- `npm run build` が通り、GitHub Pages 公開 URL で動作
